# ATLANTA — маркет подарков Telegram

Статичная витрина коллекционных подарков в стиле ATLANTA. При открытии из бота работает как полноэкранный Telegram Mini App; при прямом открытии в браузере показывается в оболочке телефона. Покупка и продажа подарков не предусмотрены.

## Открыть

Откройте `index.html` в браузере — сборка не нужна.

## Что внутри

- поиск по названию подарка и модели;
- сортировка по умолчанию — «Сначала дешёвые»; также доступны «По порядку», «Сначала дорогие» и «По названию»;
- все 124 подарка из каталога `@GiftChanges` с вашими флорами из 125 строк; цены указаны в `GRAM` с подписью шрифтом Unbounded;
- витрина показывает отдельные карточки под разными моделями: 7 карточек `Chill Flame`, 3 карточки `Big Year` и по 7 моделей у остальных подарков, где они есть; цена каждой модели отличается от флора коллекции;
- вкладка «Коллекции» показывает только коллекции, без подписи модели;
- нижняя навигация: Маркет, Коллекции, Инвентарь, Профиль;
- «История пополнений» и «Настройки» открываются как отдельные экраны с кнопкой «Назад»;
- карточка подарка открывается шторкой снизу с ценой, моделью, фоном и символом;
- блок в инвентаре «Есть подарки в Telegram?» с кнопкой «Как добавить?» и вежливой инструкцией по боту `@atlanta_holder`;
- кнопка «Пополнить счёт» показывает сообщение о неполадках на стороне сервиса приёма платежей;
- подпись «Спасибо @GiftChanges за API (api.changes.tg)» видна в мини-аппе.

Каталог задан в `catalog.js`, флоры — в `floors.js`, фоны и символы — в `decor.js`: 8 776 фонов и 26 327 символов из `@GiftChanges`. Вместо серых градиентов карточки используют настоящие цвета фона (`centerColor`, `edgeColor`, `patternColor`) и PNG символа поверх них. В присланном списке было 125 строк: дубль `Myth Mask` схлопнут, минимальная цена сохранена. Изображение и название модели берутся из одной записи каталога; для `Artisan Brick` в коллекциях оставлено исходное изображение `Gold Bar`. Для картинок нужен интернет.

## Анимации

Только спокойные переходы: плавное открытие шторок, мягкие состояния кнопок и карточек, без «плавающих» подарков и пружинных скачков.
