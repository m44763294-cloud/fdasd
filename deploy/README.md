# Перенос базы на хост бота

Файл `kustos.db` в этой папке — консистентный снимок локальной базы сделок, балансов и прав арбитров.

**Важно:** репозиторий должен быть приватным. В базе есть Telegram ID, балансы и история сделок.

## Как использовать

1. На хост-боте создайте папку `data/`.
2. Скопируйте `deploy/kustos.db` в `data/kustos.db`.
3. Не копируйте локальные `kustos.db-wal` и `kustos.db-shm` — снимок уже содержит все данные.
4. Запустите сервис с `DB_PATH=data/kustos.db` (значение по умолчанию).

После этого сделки, балансы и `@atlanta_holder` как главный арбитр сохранятся.
